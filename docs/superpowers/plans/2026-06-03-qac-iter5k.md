# qac iter-5k — operator actions endpoint Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`).

**Goal:** `POST /api/runs/{id}/actions` lets an operator `advance` a gated `review`/`ai_assess` step or `signoff` the `signoff` step; the walk resumes and sign-off yields `signed_off`.

**Architecture:** Grow `OperatorActionPayload` (StepID + signoff fields); teach `stepIDsFromEvents` to mark an `OperatorAction`'s step `seen` so a re-`Kick` advances the walk; add a validating handler that appends the event + re-Kicks.

**Tech Stack:** Go 1.23 (bare module `qac`), `net/http` ServeMux 1.22. Spec: `docs/superpowers/specs/2026-06-03-qac-iter5k-design.md`.

---

## Key facts
- `internal/engine/event.go`: `OperatorActionPayload{Action string}`; `KindOperatorAction = "OperatorAction"`.
- `internal/engine/runner.go`: walk halts at `review`/`ai_assess`/`signoff` (line ~93, emits nothing). `stepIDsFromEvents` (line 187) marks `seen` only for StepStarted/StepCompleted/StepFailed. `findNextRunnableStep` returns the first non-seen, non-skipped step.
- `internal/store/events.go`: local `operatorActionPayload{Action string}` (iter-5i); OperatorAction case → signoff sets `signed_off`, else bump updated_at.
- `internal/engine/project.go`: OperatorAction `if p.Action == "signoff"` → signed_off (`OperatorActionPayload`).
- API handlers get `eng *engine.Engine` + `s *store.Store` (see `createRunHandler`, `runs.go:105`); `Router` already threads `eng`. Error helpers: `writeError(w, status, code, msg)`, codes `codeNotFound`/`codeInvalidRequest`/`codeInternal`; `writeJSON`. Template load path: `store.LoadEvents` → first RunCreated `template_id` → `store.GetTemplate` → `template.Parse`.
- Template gated step example: `operator_signoff` (kind `signoff`, `final_verdict_options: [pass, fail]`, fields signer_name/signer_role/final_notes); `evidence_review` (review); `ai_summary` (ai_assess).

Create `internal/api/actions.go`:
```go
type operatorActionRequest struct {
	StepID     string `json:"step_id"`
	Action     string `json:"action"`
	Verdict    string `json:"verdict"`
	SignerName string `json:"signer_name"`
	SignerRole string `json:"signer_role"`
	Notes      string `json:"notes"`
}

func operatorActionHandler(s *store.Store, eng *engine.Engine) http.HandlerFunc {
	return func(w http.ResponseWriter, r *http.Request) {
		runID := r.PathValue("id")
		var req operatorActionRequest
		if err := json.NewDecoder(r.Body).Decode(&req); err != nil {
			writeError(w, http.StatusBadRequest, codeInvalidRequest, "Invalid JSON body")
			return
		}
		// Load events + template.
		evs, err := s.LoadEvents(r.Context(), runID)
		if err != nil || len(evs) == 0 {
			writeError(w, http.StatusNotFound, codeNotFound, "Run not found")
			return
		}
		tpl, ok, err := loadTemplateForRun(r.Context(), s, evs) // helper: RunCreated→template_id→GetTemplate→Parse
		if err != nil || !ok {
			writeError(w, http.StatusNotFound, codeNotFound, "Template not found for run")
			return
		}
		// Find the gated steps in order; determine which are already actioned.
		gated := gatedSteps(tpl)                  // []template.Step with kind in {review,ai_assess,signoff}
		actioned := operatorActionedStepIDs(evs)  // set of step_ids with an OperatorAction
		current, ok := firstUnactionedGated(gated, actioned)
		if !ok || current.ID != req.StepID {
			writeError(w, http.StatusUnprocessableEntity, codeInvalidRequest, "step_id is not the run's current gated step")
			return
		}
		// Validate action vs kind + signoff fields.
		switch current.Kind {
		case "review", "ai_assess":
			if req.Action != "advance" {
				writeError(w, http.StatusUnprocessableEntity, codeInvalidRequest, "this step accepts action 'advance'")
				return
			}
		case "signoff":
			if req.Action != "signoff" {
				writeError(w, http.StatusUnprocessableEntity, codeInvalidRequest, "this step accepts action 'signoff'")
				return
			}
			if req.SignerName == "" || req.SignerRole == "" {
				writeError(w, http.StatusUnprocessableEntity, codeInvalidRequest, "signoff requires signer_name and signer_role")
				return
			}
			if !verdictAllowed(current, req.Verdict) { // req.Verdict in current.FinalVerdictOptions
				writeError(w, http.StatusUnprocessableEntity, codeInvalidRequest, "verdict not in final_verdict_options")
				return
			}
		}
		// Append the event, then resume the walk.
		payload, _ := json.Marshal(engine.OperatorActionPayload{
			StepID: req.StepID, Action: req.Action, Verdict: req.Verdict,
			SignerName: req.SignerName, SignerRole: req.SignerRole, Notes: req.Notes,
		})
		if err := s.AppendEvent(r.Context(), runID, engine.KindOperatorAction, payload); err != nil {
			writeError(w, http.StatusInternalServerError, codeInternal, "Failed to record action")
			return
		}
		eng.Kick(r.Context(), runID)
		// Return the (possibly not-yet-advanced) run; never 500 after a successful append.
		runs, _ := s.ListRuns(r.Context())
		for i := range runs {
			if runs[i].ID == runID {
				writeJSON(w, http.StatusOK, map[string]any{"run": runs[i]})
				return
			}
		}
		writeJSON(w, http.StatusOK, map[string]any{"run": map[string]any{"id": runID}})
	}
}
```
Implement the helpers in `actions.go`: `loadTemplateForRun` (mirror how `createRunHandler`/`engine.loadTemplateFromEvents` resolves the template — decode first RunCreated for `template_id`, `s.GetTemplate`, `template.Parse` the stored body/parsed_json), `gatedSteps`, `operatorActionedStepIDs` (decode OperatorAction events → set of StepID), `firstUnactionedGated`, `verdictAllowed` (check `template.Step`'s final-verdict-options field — read the actual field name in `template/types.go`). Confirm `codeInvalidRequest` is the right code for 422 (check how `runs.go` returns 422 `template_not_found`/`invalid_request`).
