# qac iter-5a — RLCC + FLCC clients backed by Sourcegraph Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port the RLCC and FLCC workflow definitions from their upstream Helm chart `values.yaml` files into qac as typed Go data. Production reads come from Sourcegraph via a shared low-level HTTP client; tests and offline dev use a code-generated fixture parsed from vendored snapshots. Expose read-only HTTP routes for the iter-5b wizard to consume.

**Architecture:** Three new packages under `internal/`. `internal/sourcegraph/` is a generic raw-file fetcher with TTL cache + stale-while-revalidate, shared by both clients. `internal/rlccclient/` and `internal/flccclient/` mirror each other: each has `types.go`, `parse.go` (YAML → typed structs with derived fields), a `MapClient` backed by a code-generated `Fixture`, and a `SourcegraphClient` for live reads. `cmd/genrlccfixture` parses vendored testdata at `go generate` time and emits both `fixture_gen.go` files; a round-trip test enforces no drift between testdata and Fixture.

**Tech Stack:** Go 1.26.3 (bare `qac` module), `gopkg.in/yaml.v3` (already an indirect dep — promoted to direct in Task 5), `net/http/httptest` for client tests, stdlib only beyond YAML. Backend-only — `web/` is untouched.

🟦 **Go idiom — env-var-at-startup vs env-var-on-demand.** Reading `os.Getenv("AWXCTL_SOURCEGRAPH_TOKEN")` inside every Fetch call is tempting but wrong: the operator can change env vars between calls, the test harness has no easy way to inject a different value, and slog can't report the auth posture at startup. This is the same pattern Go's stdlib uses for things like `net/http.DefaultTransport` configuration: capture state at construction.

// Package sourcegraph is a low-level HTTP client for fetching raw files from
// CoreWeave's Sourcegraph instance. It is shared by internal/rlccclient and
// internal/flccclient, and intentionally knows nothing about RLCC/FLCC
// semantics — it returns bytes plus the resolved commit SHA.
package sourcegraph

import (
	"errors"
	"net/http"
	"os"
	"strings"
	"time"
)

// ErrNoToken is returned by NewClient when AWXCTL_SOURCEGRAPH_TOKEN is unset.
// Callers (cmd/qac/serve.go) treat this as a signal to fall through to a
// MapClient backend rather than a fatal startup error.
var ErrNoToken = errors.New("AWXCTL_SOURCEGRAPH_TOKEN unset")

// SourceRef is the (chart_tag, sha) pair returned alongside fetched content.
// ChartTag is set by callers from their own knowledge of the chart version
// pinned in testdata (sourcegraph itself does not know about chart tags).
type SourceRef struct {
	ChartTag string `json:"chart_tag"`
	SHA      string `json:"sha"`
}

// FetchResult is the body + resolved SHA returned by Fetch.
type FetchResult struct {
	Body []byte
	SHA  string
}

// Client is the shared raw-file fetcher. baseURL is the Sourcegraph root
// (e.g. "https://sourcegraph.coreweave.com") with no trailing slash. token is
// the bearer token sent on every request. httpDo is swappable for tests.
type Client struct {
	token   string
	baseURL string
	httpDo  func(*http.Request) (*http.Response, error)
	cache   *ttlCache
}

// NewClient constructs a Client. The token is read from
// AWXCTL_SOURCEGRAPH_TOKEN at construction time; an empty value returns
// ErrNoToken. baseURL has any trailing slash trimmed so call sites can
// concatenate paths without doubled "/".
func NewClient(baseURL string) (*Client, error) {
	tok := os.Getenv("AWXCTL_SOURCEGRAPH_TOKEN")
	if tok == "" {
		return nil, ErrNoToken
	}
	return &Client{
		token:   tok,
		baseURL: strings.TrimRight(baseURL, "/"),
		httpDo:  http.DefaultClient.Do,
		cache:   newTTLCache(5 * time.Minute),
	}, nil
}
```

import (
	"context"
	"fmt"
	"io"
)

// Fetch returns the raw file body at repo@ref/path. The resolved commit SHA
// comes from the X-Sourcegraph-Resolved-Revision response header; Task 3
// will add a GraphQL fallback when that header is absent.
//
// Cache lookup lands in Task 4 — this implementation always hits the network.
func (c *Client) Fetch(ctx context.Context, repo, path, ref string) (FetchResult, error) {
	url := fmt.Sprintf("%s/.api/repos/%s@%s/-/raw/%s", c.baseURL, repo, ref, path)
	req, err := http.NewRequestWithContext(ctx, http.MethodGet, url, nil)
	if err != nil {
		return FetchResult{}, fmt.Errorf("build request: %w", err)
	}
	req.Header.Set("Authorization", "token "+c.token)
	resp, err := c.httpDo(req)
	if err != nil {
		return FetchResult{}, fmt.Errorf("http: %w", err)
	}
	defer resp.Body.Close()
	if resp.StatusCode != http.StatusOK {
		return FetchResult{}, fmt.Errorf("sourcegraph %s: status %d", url, resp.StatusCode)
	}
	body, err := io.ReadAll(resp.Body)
	if err != nil {
		return FetchResult{}, fmt.Errorf("read body: %w", err)
	}
	sha := resp.Header.Get("X-Sourcegraph-Resolved-Revision")
	return FetchResult{Body: body, SHA: sha}, nil
}
```

### Task 4: TTL cache with stale-while-revalidate

**Why:** Wizard render hits `/api/rlcc/workflows` on every page load. Without a cache, every render is an HTTP round-trip to Sourcegraph. The TTL is 5 minutes for fresh; entries aged 5-30 minutes return stale + background refresh; older than 30 minutes blocks for a synchronous refetch.

**Files:**
- Modify: `internal/sourcegraph/cache.go`
- Modify: `internal/sourcegraph/client.go` (Fetch consults the cache)
- Create: `internal/sourcegraph/cache_test.go`

🟦 **Go idiom — stale-while-revalidate.** Classic web-caching pattern: never block the request path on a backend refresh if you have *any* recent answer. The synchronous refetch only fires when the data is genuinely too old to serve. In Go, the "fire background refresh" line is just `go c.refresh(...)` — one keyword, one extra goroutine per stale-but-young hit.

🟦 **Go idiom — `sync.Mutex` over `sync.RWMutex` for short critical sections.** A 5-entry map read is fast enough that the RWMutex bookkeeping is not worth it; reach for RWMutex only when reads dominate and the critical section is longer than a map lookup.

func TestCache_RefreshDeduplication(t *testing.T) {
	c := newTTLCache(5 * time.Minute)
	c.putAt("k", FetchResult{Body: []byte("old")}, time.Now().Add(-10*time.Minute))
	var calls int64
	refresh := func() (FetchResult, error) {
		atomic.AddInt64(&calls, 1)
		time.Sleep(20 * time.Millisecond)
		return FetchResult{Body: []byte("new")}, nil
	}
	// Two simultaneous stale-young hits should issue exactly ONE refresh.
	c.scheduleRefresh("k", refresh)
	c.scheduleRefresh("k", refresh)

		t.Errorf("refresh calls = %d, want 1 (dedup)", calls)
	}

package sourcegraph

import (
	"sync"
	"time"
)

type cacheStatus int

const (
	cacheMiss cacheStatus = iota
	cacheFresh
	cacheStaleYoung // past TTL but within staleMax — return + refresh in bg
	cacheStaleOld   // past staleMax — caller must synchronously refetch
)

const staleMax = 30 * time.Minute

type cacheEntry struct {
	res       FetchResult
	createdAt time.Time
}

type ttlCache struct {
	ttl        time.Duration
	mu         sync.Mutex
	entries    map[string]cacheEntry
	inFlight   map[string]struct{} // refresh deduplication
}

func newTTLCache(ttl time.Duration) *ttlCache {
	return &ttlCache{
		ttl:      ttl,
		entries:  map[string]cacheEntry{},
		inFlight: map[string]struct{}{},
	}
}

func (c *ttlCache) put(key string, res FetchResult) {
	c.putAt(key, res, time.Now())
}

func (c *ttlCache) putAt(key string, res FetchResult, at time.Time) {
	c.mu.Lock()
	c.entries[key] = cacheEntry{res: res, createdAt: at}
	c.mu.Unlock()
}

// get returns the cached entry only when fresh. Use lookup for stale-aware reads.
func (c *ttlCache) get(key string, now time.Time) (FetchResult, bool) {
	res, status := c.lookup(key, now)
	return res, status == cacheFresh
}

func (c *ttlCache) lookup(key string, now time.Time) (FetchResult, cacheStatus) {
	c.mu.Lock()
	defer c.mu.Unlock()
	e, ok := c.entries[key]
	if !ok {
		return FetchResult{}, cacheMiss
	}
	age := now.Sub(e.createdAt)
	switch {
	case age < c.ttl:
		return e.res, cacheFresh
	case age < staleMax:
		return e.res, cacheStaleYoung
	default:
		return e.res, cacheStaleOld
	}
}

func (c *ttlCache) Purge() {
	c.mu.Lock()
	c.entries = map[string]cacheEntry{}
	c.mu.Unlock()
}

// scheduleRefresh runs fn in a goroutine if no refresh for key is already in
// flight. The result replaces the cached value on success.
func (c *ttlCache) scheduleRefresh(key string, fn func() (FetchResult, error)) {
	c.mu.Lock()
	if _, busy := c.inFlight[key]; busy {
		c.mu.Unlock()
		return
	}
	c.inFlight[key] = struct{}{}
	c.mu.Unlock()
	go func() {
		defer func() {
			c.mu.Lock()
			delete(c.inFlight, key)
			c.mu.Unlock()
		}()
		res, err := fn()
		if err != nil {
			return
		}
		c.put(key, res)
	}()
}
```

func (c *Client) Fetch(ctx context.Context, repo, path, ref string) (FetchResult, error) {
	key := repo + "@" + ref + "/" + path
	now := time.Now()
	cached, status := c.cache.lookup(key, now)
	switch status {
	case cacheFresh:
		return cached, nil
	case cacheStaleYoung:
		c.cache.scheduleRefresh(key, func() (FetchResult, error) {
			return c.fetchNetwork(context.Background(), repo, path, ref)
		})
		return cached, nil
	}
	// cacheMiss or cacheStaleOld: synchronous fetch.
	res, err := c.fetchNetwork(ctx, repo, path, ref)
	if err != nil {
		return FetchResult{}, err
	}
	c.cache.put(key, res)
	return res, nil
}

func (c *Client) fetchNetwork(ctx context.Context, repo, path, ref string) (FetchResult, error) {
	url := fmt.Sprintf("%s/.api/repos/%s@%s/-/raw/%s", c.baseURL, repo, ref, path)
	req, err := http.NewRequestWithContext(ctx, http.MethodGet, url, nil)
	if err != nil {
		return FetchResult{}, fmt.Errorf("build request: %w", err)
	}
	req.Header.Set("Authorization", "token "+c.token)
	resp, err := c.httpDo(req)
	if err != nil {
		return FetchResult{}, fmt.Errorf("http: %w", err)
	}
	defer resp.Body.Close()
	if resp.StatusCode != http.StatusOK {
		return FetchResult{}, fmt.Errorf("sourcegraph %s: status %d", url, resp.StatusCode)
	}
	body, err := io.ReadAll(resp.Body)
	if err != nil {
		return FetchResult{}, fmt.Errorf("read body: %w", err)
	}
	sha := resp.Header.Get("X-Sourcegraph-Resolved-Revision")
	if sha == "" {
		sha = c.resolveSHAViaGraphQL(ctx, repo, ref)
	}
	return FetchResult{Body: body, SHA: sha}, nil

package rlccclient

import (
	"fmt"
	"io"
	"strings"

	"gopkg.in/yaml.v3"
)

// rlccTop is the wire-shape of the chart's values.yaml. qac only cares
// about the workflows[] block; everything else (image, triggers, platforms,
// metrics, ...) is ignored by the unmarshaler.
type rlccTop struct {
	RLCC struct {
		Workflows []WorkflowGraph `yaml:"workflows"`
	} `yaml:"rlcc"`
}

// ParseValuesYAML decodes the rack-lifecycle-controller chart values.yaml
// into a name -> WorkflowGraph map. It derives RackKind from the workflow
// name prefix and ActionCount from len(Actions). Unknown handler kinds and
// unknown component kinds pass through verbatim (they're just strings under
// the hood).
func ParseValuesYAML(r io.Reader) (map[string]WorkflowGraph, error) {
	body, err := io.ReadAll(r)
	if err != nil {
		return nil, fmt.Errorf("read: %w", err)
	}
	var top rlccTop
	if err := yaml.Unmarshal(body, &top); err != nil {
		return nil, fmt.Errorf("yaml unmarshal: %w", err)
	}
	out := make(map[string]WorkflowGraph, len(top.RLCC.Workflows))
	for _, g := range top.RLCC.Workflows {
		g.RackKind = rackKindFromName(g.Name)
		g.ActionCount = len(g.Actions)
		out[g.Name] = g
	}
	return out, nil
}

// rackKindFromName buckets a workflow name by its hardware prefix. Unknown
// prefixes return "" — the UI can group those under "other" or hide them.
func rackKindFromName(name string) string {
	for _, p := range []string{"gb200", "b300", "gbx00", "b200", "bx00"} {
		if strings.HasPrefix(name, p+"-") || name == p {
			return p
		}
	}
	return ""
}

package rlccclient

import (
	"bytes"
	"context"
	"errors"
	"fmt"

	"qac/internal/sourcegraph"
)

const (
	rlccRepo = "github.com/coreweave/rack-lifecycle-controller"
	rlccPath = "chart/rack-lifecycle-controller/values.yaml"
	rlccRef  = "main"
)

// SourcegraphClient reads the RLCC chart values.yaml live from Sourcegraph.
// Caching lives one layer down (in sourcegraph.Client); this layer just
// parses and reports the chart tag.
type SourcegraphClient struct {
	sg       *sourcegraph.Client
	chartTag string // currently unknown without a side channel; defaults to ""
}

// NewSourcegraphClient wraps a sourcegraph.Client. ChartTag is left empty —
// the SHA returned by Fetch is the load-bearing pinning identifier; the
// chart tag is informational only.
func NewSourcegraphClient(sg *sourcegraph.Client) *SourcegraphClient {
	return &SourcegraphClient{sg: sg}
}

func (c *SourcegraphClient) catalog(ctx context.Context) (map[string]WorkflowGraph, SourceRef, error) {
	res, err := c.sg.Fetch(ctx, rlccRepo, rlccPath, rlccRef)
	if err != nil {
		return nil, SourceRef{}, fmt.Errorf("fetch rlcc values.yaml: %w", err)
	}
	m, err := ParseValuesYAML(bytes.NewReader(res.Body))
	if err != nil {
		return nil, SourceRef{}, fmt.Errorf("parse rlcc values.yaml: %w", err)
	}
	return m, SourceRef{ChartTag: c.chartTag, SHA: res.SHA}, nil
}

func (c *SourcegraphClient) ListWorkflows(ctx context.Context) ([]WorkflowSummary, SourceRef, error) {
	m, src, err := c.catalog(ctx)
	if err != nil {
		return nil, src, err
	}
	out := make([]WorkflowSummary, 0, len(m))
	for _, g := range m {
		out = append(out, g.WorkflowSummary)
	}
	// Sort to match MapClient's stable order.
	sortByName(out)
	return out, src, nil
}

func (c *SourcegraphClient) GetWorkflow(ctx context.Context, name string) (WorkflowGraph, SourceRef, error) {
	m, src, err := c.catalog(ctx)
	if err != nil {
		return WorkflowGraph{}, src, err
	}
	g, ok := m[name]
	if !ok {
		return WorkflowGraph{}, src, fmt.Errorf("%w: %s", ErrWorkflowNotFound, name)
	}
	return g, src, nil
}

func sortByName(s []WorkflowSummary) {
	for i := 1; i < len(s); i++ {
		for j := i; j > 0 && s[j-1].Name > s[j].Name; j-- {
			s[j], s[j-1] = s[j-1], s[j]
		}
	}
}

var _ = errors.New // keep errors import alive in case future error wrapping lands

// Package flccclient exposes FLCC workflow definitions as typed Go data.
// Production reads come from Sourcegraph via internal/sourcegraph.Client;
// tests and offline dev use a code-generated Fixture. Mirrors
// internal/rlccclient/.
package flccclient

import "qac/internal/sourcegraph"

// PhaseClass buckets FLCC workflows by which controller drives them.
type PhaseClass string

const (
	PhaseClassRackProvision PhaseClass = "rack-provision"
	PhaseClassNodeProvision PhaseClass = "node-provision"
)

// FLCCWorkflowSummary is the picker-level view of one FLCC workflow.
// PhaseCount and TerminalPhase are derived in parse.go.
type FLCCWorkflowSummary struct {
	Name          string     `yaml:"name"        json:"name"`
	Class         PhaseClass `yaml:"class"       json:"class"`
	Description   string     `yaml:"description" json:"description"`
	PhaseCount    int        `yaml:"-"           json:"phase_count"`
	TerminalPhase string     `yaml:"-"           json:"terminal_phase"`
}

// FLCCWorkflowGraph is the full ordered view including phases[].
type FLCCWorkflowGraph struct {
	FLCCWorkflowSummary `yaml:",inline"`
	Phases              []FLCCPhase `yaml:"phases" json:"phases"`
}

// FLCCPhase pins a node state, with watchdog timeout, failState transition,
// optional poll interval, and a free-form parameters map.
type FLCCPhase struct {
	Name        string            `yaml:"name"                  json:"name"`
	State       string            `yaml:"state"                 json:"state"`
	Timeout     string            `yaml:"timeout,omitempty"     json:"timeout,omitempty"`
	FailState   string            `yaml:"failState,omitempty"   json:"fail_state,omitempty"`
	RequeueTime string            `yaml:"requeueTime,omitempty" json:"requeue_time,omitempty"`
	Parameters  map[string]string `yaml:"parameters,omitempty"  json:"parameters,omitempty"`
}

// SourceRef re-exports sourcegraph.SourceRef so callers don't have to
// import sourcegraph for the (chart_tag, sha) pair.
type SourceRef = sourcegraph.SourceRef
```

package flccclient

import (
	"fmt"
	"io"

	"gopkg.in/yaml.v3"
)

// flccTop is the wire-shape of the FLCC chart values.yaml. qac only cares
// about flcc.config.workflows; everything else (apiServer, flcc.app,
// workflowOverrides, ...) is ignored.
type flccTop struct {
	FLCC struct {
		Config struct {
			Workflows []FLCCWorkflowGraph `yaml:"workflows"`
		} `yaml:"config"`
	} `yaml:"flcc"`
}

// ParseValuesYAML decodes the fleet-lifecycle-controller chart values.yaml
// into a name -> FLCCWorkflowGraph map. Derives PhaseCount (= len(Phases))
// and TerminalPhase (= last phase's State).
func ParseValuesYAML(r io.Reader) (map[string]FLCCWorkflowGraph, error) {
	body, err := io.ReadAll(r)
	if err != nil {
		return nil, fmt.Errorf("read: %w", err)
	}
	var top flccTop
	if err := yaml.Unmarshal(body, &top); err != nil {
		return nil, fmt.Errorf("yaml unmarshal: %w", err)
	}
	out := make(map[string]FLCCWorkflowGraph, len(top.FLCC.Config.Workflows))
	for _, g := range top.FLCC.Config.Workflows {
		g.PhaseCount = len(g.Phases)
		if g.PhaseCount > 0 {
			g.TerminalPhase = g.Phases[len(g.Phases)-1].State
		}
		out[g.Name] = g
	}
	return out, nil
}

package flccclient

import (
	"context"
	"errors"
	"fmt"
	"sort"
)

var ErrWorkflowNotFound = errors.New("flcc workflow not found")

// Client is the read-only FLCC catalog. TerminalPhase is the load-bearing
// extra over RLCC: the iter-5b step rail calls it to resolve
// components.computetray.workflow -> "waits for <terminal>" labels.
type Client interface {
	ListWorkflows(ctx context.Context) ([]FLCCWorkflowSummary, SourceRef, error)
	GetWorkflow(ctx context.Context, name string) (FLCCWorkflowGraph, SourceRef, error)
	TerminalPhase(ctx context.Context, name string) (string, error)
}

type MapClient struct {
	fixture map[string]FLCCWorkflowGraph
	source  SourceRef
}

func NewMapClient() *MapClient {
	return &MapClient{
		fixture: Fixture,
		source:  SourceRef{ChartTag: FixtureChartTag, SHA: FixtureSHA},
	}
}

func (c *MapClient) ListWorkflows(_ context.Context) ([]FLCCWorkflowSummary, SourceRef, error) {
	out := make([]FLCCWorkflowSummary, 0, len(c.fixture))
	for _, g := range c.fixture {
		out = append(out, g.FLCCWorkflowSummary)
	}
	sort.Slice(out, func(i, j int) bool { return out[i].Name < out[j].Name })
	return out, c.source, nil
}

func (c *MapClient) GetWorkflow(_ context.Context, name string) (FLCCWorkflowGraph, SourceRef, error) {
	g, ok := c.fixture[name]
	if !ok {
		return FLCCWorkflowGraph{}, c.source, fmt.Errorf("%w: %s", ErrWorkflowNotFound, name)
	}
	return g, c.source, nil
}

func (c *MapClient) TerminalPhase(_ context.Context, name string) (string, error) {
	g, ok := c.fixture[name]
	if !ok {
		return "", fmt.Errorf("%w: %s", ErrWorkflowNotFound, name)
	}
	return g.TerminalPhase, nil
}

package flccclient

import (
	"bytes"
	"context"
	"fmt"

	"qac/internal/sourcegraph"
)

const (
	flccRepo = "github.com/coreweave/fleet-lifecycle-controller"
	flccPath = "chart/values.yaml"
	flccRef  = "develop"
)

type SourcegraphClient struct {
	sg       *sourcegraph.Client
	chartTag string
}

func NewSourcegraphClient(sg *sourcegraph.Client) *SourcegraphClient {
	return &SourcegraphClient{sg: sg}
}

func (c *SourcegraphClient) catalog(ctx context.Context) (map[string]FLCCWorkflowGraph, SourceRef, error) {
	res, err := c.sg.Fetch(ctx, flccRepo, flccPath, flccRef)
	if err != nil {
		return nil, SourceRef{}, fmt.Errorf("fetch flcc values.yaml: %w", err)
	}
	m, err := ParseValuesYAML(bytes.NewReader(res.Body))
	if err != nil {
		return nil, SourceRef{}, fmt.Errorf("parse flcc values.yaml: %w", err)
	}
	return m, SourceRef{ChartTag: c.chartTag, SHA: res.SHA}, nil
}

func (c *SourcegraphClient) ListWorkflows(ctx context.Context) ([]FLCCWorkflowSummary, SourceRef, error) {
	m, src, err := c.catalog(ctx)
	if err != nil {
		return nil, src, err
	}
	out := make([]FLCCWorkflowSummary, 0, len(m))
	for _, g := range m {
		out = append(out, g.FLCCWorkflowSummary)
	}
	return out, src, nil
}

func (c *SourcegraphClient) GetWorkflow(ctx context.Context, name string) (FLCCWorkflowGraph, SourceRef, error) {
	m, src, err := c.catalog(ctx)
	if err != nil {
		return FLCCWorkflowGraph{}, src, err
	}
	g, ok := m[name]
	if !ok {
		return FLCCWorkflowGraph{}, src, fmt.Errorf("%w: %s", ErrWorkflowNotFound, name)
	}
	return g, src, nil
}

func (c *SourcegraphClient) TerminalPhase(ctx context.Context, name string) (string, error) {
	m, _, err := c.catalog(ctx)
	if err != nil {
		return "", err
	}
	g, ok := m[name]
	if !ok {
		return "", fmt.Errorf("%w: %s", ErrWorkflowNotFound, name)
	}
	return g.TerminalPhase, nil

// Command genrlccfixture is a code generator for the rlccclient and
// flccclient packages. It parses a chart's values.yaml and emits a
// fixture_gen.go containing the in-memory catalog map.
//
// Two modes:
//   -mode rlcc   parses internal/rlccclient/testdata/rlcc-values.yaml
//                and writes internal/rlccclient/fixture_gen.go (default).
//   -mode flcc   parses internal/flccclient/testdata/flcc-values.yaml
//                and writes internal/flccclient/fixture_gen.go.
//
// Run via go generate (directives live in client.go in each target package).
package main

import (
	"bytes"
	"flag"
	"fmt"
	"go/format"
	"os"
	"sort"
	"text/template"

	"qac/internal/flccclient"
	"qac/internal/rlccclient"
)

var rlccTpl = template.Must(template.New("rlcc").Parse(`// Code generated by cmd/genrlccfixture; DO NOT EDIT.
package rlccclient

const FixtureChartTag = {{ printf "%q" .ChartTag }}
const FixtureSHA = {{ printf "%q" .SHA }}

var Fixture = map[string]WorkflowGraph{
{{- range .Names }}
	{{ printf "%q" . }}: {{ index $.Graphs . | printf "%#v" }},
{{- end }}
}
`))

var flccTpl = template.Must(template.New("flcc").Parse(`// Code generated by cmd/genrlccfixture; DO NOT EDIT.
package flccclient

const FixtureChartTag = {{ printf "%q" .ChartTag }}
const FixtureSHA = {{ printf "%q" .SHA }}

var Fixture = map[string]FLCCWorkflowGraph{
{{- range .Names }}
	{{ printf "%q" . }}: {{ index $.Graphs . | printf "%#v" }},
{{- end }}
}
`))

type rlccTplData struct {
	ChartTag string
	SHA      string
	Names    []string
	Graphs   map[string]rlccclient.WorkflowGraph
}

type flccTplData struct {
	ChartTag string
	SHA      string
	Names    []string
	Graphs   map[string]flccclient.FLCCWorkflowGraph
}

func main() {
	mode := flag.String("mode", "rlcc", "rlcc or flcc")
	in := flag.String("in", "", "input YAML path (required)")
	out := flag.String("out", "", "output Go path (required)")
	chartTag := flag.String("tag", "", "FixtureChartTag value")
	sha := flag.String("sha", "vendored", "FixtureSHA value")
	flag.Parse()
	if *in == "" || *out == "" {
		fmt.Fprintln(os.Stderr, "genrlccfixture: -in and -out are required")
		os.Exit(2)
	}

	body, err := os.ReadFile(*in)
	must(err, "read %s", *in)

	var rendered []byte
	switch *mode {
	case "rlcc":
		m, err := rlccclient.ParseValuesYAML(bytes.NewReader(body))
		must(err, "parse rlcc")
		names := sortedKeys(m)
		var buf bytes.Buffer
		must(rlccTpl.Execute(&buf, rlccTplData{ChartTag: *chartTag, SHA: *sha, Names: names, Graphs: m}), "render rlcc")
		rendered = buf.Bytes()
	case "flcc":
		m, err := flccclient.ParseValuesYAML(bytes.NewReader(body))
		must(err, "parse flcc")
		names := sortedFLCCKeys(m)
		var buf bytes.Buffer
		must(flccTpl.Execute(&buf, flccTplData{ChartTag: *chartTag, SHA: *sha, Names: names, Graphs: m}), "render flcc")
		rendered = buf.Bytes()
	default:
		fmt.Fprintf(os.Stderr, "genrlccfixture: unknown -mode %q\n", *mode)
		os.Exit(2)
	}

	formatted, err := format.Source(rendered)
	must(err, "gofmt")
	must(os.WriteFile(*out, formatted, 0o644), "write %s", *out)
	fmt.Fprintf(os.Stderr, "genrlccfixture: wrote %s\n", *out)
}

func sortedKeys(m map[string]rlccclient.WorkflowGraph) []string {
	out := make([]string, 0, len(m))
	for k := range m {
		out = append(out, k)
	}
	sort.Strings(out)
	return out
}

func sortedFLCCKeys(m map[string]flccclient.FLCCWorkflowGraph) []string {
	out := make([]string, 0, len(m))
	for k := range m {
		out = append(out, k)
	}
	sort.Strings(out)
	return out
}

func must(err error, fmtStr string, args ...any) {
	if err != nil {
		fmt.Fprintf(os.Stderr, "genrlccfixture: "+fmtStr+": %v\n", append(args, err)...)
		os.Exit(1)
	}
}

			"source":    src,
		})
	}
}
