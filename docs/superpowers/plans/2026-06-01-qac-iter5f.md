# qac iter-5f — Wire rlcc_action_probe Into the Canary Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `rlcc_action_probe` run for real, end-to-end, through the live engine on the canonical template — the first genuine exercise of the probe outside hand-written fakes.

**Architecture:** Three sequential changes. (1) Relax the template validator so a `kind: probe` step may carry both `probe_type` and an `action` (the latter as a config carrier — the runner already maps `action.args` map-form into `StepContext.Config`). (2) Rewrite the canonical template's `l11_fielddiag` step in place (keep its `id`) to use `probe_type: rlcc_action_probe`, bumping the template version. (3) Add an integration test that drives a real run through the real probe + real map-backed clients and asserts per-CT evidence + the aggregate Output. Plus a frontend mock version sync and full verification.

**Tech Stack:** Go 1.23 (bare module `qac`), `modernc.org/sqlite`, event-sourced store, `net/http` ServeMux, `testing/fstest`. Frontend: React 18 + Vite + MSW (Yarn 4). Spec: `docs/superpowers/specs/2026-06-01-qac-iter5f-design.md`.

## Key facts discovered during planning (read first)

These ground every task — do not re-derive them:

1. **The runner already feeds config to probes.** `internal/engine/runner.go:127` sets `StepContext.Config = step.Action.Args` **when `Args` is a `map[string]any`**. The probe reads `match_handler`, `target_state`, `poll_interval` from `StepContext.Config`. So Approach A needs **zero runner change** — only the validator must stop rejecting `probe_type` + `action`.
2. **Action-tool steps are skipped, not executed.** `runner.go:103`: steps with empty `ProbeType` are skipped (no tool dispatcher). So the canary's `baseline_pre`/`zap_canary`/`l10_*`/`l11_check`/`l12_*`/`baseline_post` (all action-tool) never block on their `timeout`. `review`/`ai_assess`/`signoff` steps **halt** the walk (`runner.go:93`). The walk therefore runs `alert_baseline` → `fact_baseline` → (skips) → `l11_fielddiag` → (skips) → halts at `evidence_review`.
3. **The probe's ticker waits a full interval before its first tick** (`rlccactionprobe.go:129` `time.NewTicker(cfg.pollInterval)`), and `MapClient.QueryActionState` reports complete after **3 calls** by default (keyed by `target_state`). So `poll_interval: 30s` ⇒ ~90s to complete — far past any test timeout. **The e2e test must shrink the interval** (string-replace `poll_interval: 30s` → `poll_interval: 5ms` in the loaded YAML body): 3 ticks × 5ms ≈ 15ms.
4. **The workflow snapshot carries handlers.** `internal/api/runs.go:179` builds the snapshot as `Actions: graph.Actions`. The `gb200-rack-bringup-v4` fixture (`internal/rlccclient/fixture_gen.go:9`) includes `Action{Name: "gb200-l11-fielddiag", Handler: "l11-fielddiag"}`. So with `match_handler: l11-fielddiag`, `findAction` matches.
5. **Demo rack `dh3-r012-us-east-01a` resolves to 18 CTs** (existing canonical test asserts `ct_count == 18` and `rack_deviceslots == 18`). With no RLCC ignore seeded, all 18 are walked.
6. **Evidence table columns:** `evidence(id, run_id, step_id, content_type, payload, created_at, deviceslot)`. Per-CT rows set `deviceslot`; the engine-written aggregate Output row leaves it `NULL`.
7. **The existing test `TestCreateRun_CanonicalCanaryTemplate_LegacyShape` does NOT register `rlccactionprobe`.** After the template edit, it will hit `l11_fielddiag` as an unregistered probe type → `StepFailed` (walk continues, `runner.go:113`). Its assertions (≥2 completed for alert/fact, BMNDiscovered=1, rack_deviceslots=18, rlcc bmn_ignores=1) are unaffected and must stay green.

```go
// TestCanonicalCanary_RLCCActionProbe_EndToEnd is the first real exercise of
// rlcc_action_probe: it loads the on-disk canonical template (poll interval
// shrunk so the MapClient's 3-tick completion lands in milliseconds), drives a
// run through the live engine with the probe registered, and asserts that
// l11_fielddiag produced one per-CT evidence row per CT plus the aggregate
// Output the engine writes from the probe's return value.
func TestCanonicalCanary_RLCCActionProbe_EndToEnd(t *testing.T) {
	ctx := context.Background()
	s, err := store.Open(ctx, filepath.Join(t.TempDir(), "fwqual.db"))
	if err != nil {
		t.Fatalf("Open: %v", err)
	}
	t.Cleanup(func() { _ = s.Close() })

	// Load the real on-disk template, then shrink the probe poll interval so
	// the MapClient's default 3-tick completion finishes in ~15ms (the ticker
	// waits a full interval before its first tick — 30s would blow the
	// timeout). We still exercise the real template structure and wiring.
	raw, err := os.ReadFile(filepath.Join("..", "..", "templates", "firmware-release-canary.yaml"))
	if err != nil {
		t.Fatalf("ReadFile: %v", err)
	}
	body := strings.Replace(string(raw), "poll_interval: 30s", "poll_interval: 5ms", 1)
	if !strings.Contains(body, "poll_interval: 5ms") {
		t.Fatal("expected to rewrite poll_interval: 30s → 5ms; template shape changed?")
	}
	fsys := fstest.MapFS{
		"templates/firmware-release-canary.yaml": &fstest.MapFile{Data: []byte(body)},
	}
	if err := seed.LoadEmbeddedTemplates(ctx, s, fsys); err != nil {
		t.Fatalf("LoadEmbeddedTemplates: %v", err)
	}

	resolver := inventoryclient.NewMapResolverWithBMNs(inventoryclient.SeedDemoFixtures(), inventoryclient.SeedDemoBMNs())
	lifeC := lifecycleclient.NewMapClient(nil) // no RLCC ignores → all 18 CTs walked
	reg := probe.NewRegistry()
	reg.Register(alertprobe.New())
	reg.Register(factprobe.New())
	reg.Register(rlccactionprobe.New())
	eng := engine.New(s, reg, probe.Clients{
		AlertClient:       alertclient.NewMapAlertClient(alertclient.SeedDemoAlerts()),
		InventoryResolver: resolver,
		LifecycleClient:   lifeC,
		EvidenceWriter:    s,
		EventEmitter:      probe.NewStoreEmitter(s),
	})
	srv := httptest.NewServer(Router(s, "test", resolver, eng, rlccclient.NewMapClient(), flccclient.NewMapClient(), false, func() {}, lifeC))
	t.Cleanup(func() {
		c, cancel := context.WithTimeout(context.Background(), 2*time.Second)
		defer cancel()
		_ = eng.Shutdown(c)
	})
	t.Cleanup(srv.Close)

	reqBody := `{
    "template_id": "firmware-release-canary",
    "inputs": {
        "bundle_tag":    "gb200-fw-2026-05-canary-3",
        "canary_racks":  ["dh3-r012-us-east-01a"],
        "rlcc_workflow": "gb200-rack-bringup-v4"
    }
}`
	res, err := http.Post(srv.URL+"/api/runs", "application/json", strings.NewReader(reqBody))
	if err != nil {
		t.Fatalf("POST: %v", err)
	}
	defer res.Body.Close()
	if res.StatusCode != 201 {
		var env map[string]any
		_ = json.NewDecoder(res.Body).Decode(&env)
		t.Fatalf("status = %d, want 201; body = %+v", res.StatusCode, env)
	}
	var out struct {
		Run struct{ ID string } `json:"run"`
	}
	if err := json.NewDecoder(res.Body).Decode(&out); err != nil {
		t.Fatalf("decode: %v", err)
	}
	runID := out.Run.ID

	// Walk runs alert_baseline + fact_baseline + l11_fielddiag, then halts at
	// evidence_review (a review step). Wait for the walk to finish.
	select {
	case <-eng.Wait(runID):
	case <-time.After(5 * time.Second):
		t.Fatal("engine did not finish canary run within 5s")
	}

	// l11_fielddiag must have reached StepCompleted (the probe is a gatherer;
	// it returns a non-error Output).
	evs, err := s.LoadEvents(ctx, runID)
	if err != nil {
		t.Fatalf("LoadEvents: %v", err)
	}
	var l11Completed bool
	for _, ev := range evs {
		if ev.Kind != "StepCompleted" {
			continue
		}
		var sc struct {
			StepID string `json:"step_id"`
		}
		_ = json.Unmarshal(ev.Payload, &sc)
		if sc.StepID == "l11_fielddiag" {
			l11Completed = true
		}
	}
	if !l11Completed {
		t.Fatal("no StepCompleted for l11_fielddiag; the probe did not run end-to-end")
	}

	// 18 per-CT evidence rows (deviceslot set) for the 18-CT demo rack.
	var nPerCT int
	if err := s.DB().QueryRowContext(ctx,
		`SELECT COUNT(*) FROM evidence WHERE run_id = ? AND step_id = 'l11_fielddiag' AND deviceslot IS NOT NULL`,
		runID).Scan(&nPerCT); err != nil {
		t.Fatalf("query per-CT evidence: %v", err)
	}
	if nPerCT != 18 {
		t.Errorf("per-CT evidence rows = %d, want 18", nPerCT)
	}

	// 1 aggregate Output row (deviceslot NULL) written by the engine from the
	// probe's returned Output.
	var nAgg int
	if err := s.DB().QueryRowContext(ctx,
		`SELECT COUNT(*) FROM evidence WHERE run_id = ? AND step_id = 'l11_fielddiag' AND deviceslot IS NULL`,
		runID).Scan(&nAgg); err != nil {
		t.Fatalf("query aggregate evidence: %v", err)
	}
	if nAgg != 1 {
		t.Errorf("aggregate evidence rows = %d, want 1", nAgg)
	}

	// The aggregate Output reports all 18 CTs completed.
	var aggPayload string
	if err := s.DB().QueryRowContext(ctx,
		`SELECT payload FROM evidence WHERE run_id = ? AND step_id = 'l11_fielddiag' AND deviceslot IS NULL`,
		runID).Scan(&aggPayload); err != nil {
		t.Fatalf("scan aggregate payload: %v", err)
	}
	var agg struct {
		CountActive    int  `json:"count_active"`
		CountCompleted int  `json:"count_completed"`
		TimedOut       bool `json:"timed_out"`
	}
	if err := json.Unmarshal([]byte(aggPayload), &agg); err != nil {
		t.Fatalf("unmarshal aggregate payload %q: %v", aggPayload, err)
	}
	if agg.CountActive != 18 || agg.CountCompleted != 18 {
		t.Errorf("aggregate counts = active:%d completed:%d, want 18/18", agg.CountActive, agg.CountCompleted)
	}
	if agg.TimedOut {
		t.Error("aggregate timed_out = true, want false (all CTs completed)")
	}
}
```
